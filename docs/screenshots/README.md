# Screenshots

Put real screenshots of the app here and reference them from the main README.

1. Install the debug or release APK on a phone or emulator.
2. In AAuth open **Settings** and switch off **Protect screen content** (otherwise screenshots are black).
3. Add a demo account (for example the key `JBSWY3DPEHPK3PXP`), never a real one.
4. Take screenshots of: home list, add-account sheet, scanner, settings, lock screen.
5. Name them `home.png`, `add.png`, `scan.png`, `settings.png`, `lock.png` and commit them to this folder.
6. In `README.md`, remove the HTML comment around the screenshots table.
